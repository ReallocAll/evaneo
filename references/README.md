# Engineering references

This directory contains source-backed analyses, engineering case studies, comparisons, and decision guides for Evaneo. Evidence boundaries and source attribution remain in the relevant documents. A cited test or reported outcome is not independent runtime verification.

Browse the [engineering case studies](indexes/engineering-cases.md) by topic, see the [route map](routes.md#routes), or use `scripts/retrieve.py` from the Skill root to search for a concrete failure mode and open an exact returned section. Retrieval relevance is not correctness or consensus.
