## [feature] 1.21.70 support (#149) {#commit-fa33de07c476b06b9ad52a694b1b0545d246a931}

Explicit reason: [feature] 1.21.70 support (#149)

#### **Overview** {#overview}
This PR implements preliminary support for Minecraft Bedrock version
**1.21.70** ahead of its official release. The goal is to minimize the
update time once the version is officially available by preparing most
of the necessary changes in advance. Once 1.21.70 is released, only
function offsets will need to be updated, ensuring a seamless transition
with minimal disruption to server owners.

- This PR has been tested on the latest **1.21.70 preview build
(beta.26)** on both **Windows** and **Linux**.
- Server owners can use the preview server support as a temporary
solution when 1.21.70 is officially released, allowing players with the
new client to connect before full support is completed.
- Once **1.21.70** is officially released, we will update the offsets as
soon as possible. Since most of the work has already been completed in
this PR, full 1.21.70 support should be finalized within a day.
