## Observed change, context and limits {#observed-change-context-and-limits}

Adds platform-validated asynchronous downloads using one aiohttp session, a comma-separated UTF-8-BOM-tolerant list, temporary Custom directory and ZIP packaging. Completion is awaited through tqdm.as_completed before make_archive. Initial version writes any HTTP response body without status checking and keeps all response bytes in memory. Paths come directly from list entries and only the top-level Custom directory is created. No explicit retry, application-level concurrency cap, checksum validation, path sanitization, tests or pinning of requirements is added. requests is initially declared but unused; later removed.
