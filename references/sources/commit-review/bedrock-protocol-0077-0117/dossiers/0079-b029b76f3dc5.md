## Problem and constraints {#problem-and-constraints}

The v2168 sound-update dump lists seven repeated switch fields, which can be mistaken for independent optionals.

## Implementation and producer semantics {#implementation-and-producer-semantics}

Bound old SoundDataEvent/name-coded packet to pre2168. Model Stop, SetVolume, SetPitch, Fade(duration,target_volume), SeekTo, Pause and Resume as one uvarint32-indexed union after ServerSoundHandle.

## Stated rationale and alternatives {#stated-rationale-and-alternatives}

Message traces repeated fields to cereal tagged-variant-member bindings and uses PlayerVideoCapture's matching dump/handwritten serializer as control. It explicitly rejects Cloudburst's seven-optionals interpretation and Fade ordering.

## Tests and outcomes {#tests-and-outcomes}

Structural stop/resume index bytes, volume/fade payload order and own round trips; reverse-era rejection. Handle and float bytes are stated to be run-sourced, but no full usable v2168 golden exists.

These are tests and outcome claims examined in source. No upstream test, compiler, codec, regeneration, Windows or BDS execution was performed by this review. The cited source/byte checks are static observations, not independent runtime validation.
