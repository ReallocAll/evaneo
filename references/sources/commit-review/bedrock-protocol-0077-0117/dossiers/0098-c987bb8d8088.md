## Problem and constraints {#problem-and-constraints}

Item-stack requests and responses cerealize at2168, changing variant numbering, field widths, ingredient/item closures and conditional framing.

## Implementation and producer semantics {#implementation-and-producer-semantics}

1001 action tags include deprecated holes7/8;2168 variant excludes them and restates a uint8 action inside each payload, so LabTable becomes outer7/inner9. Two old monostates retain the holes. Slot/mine/grindstone net ids become fixed int32; autocraft drops num_ingredients, uses descriptor+uint16 count. Responses change success-gated containers to literal-true marker plus optional flag; slot netid has the same double framing. RedactableString second string becomes optional.

## Stated rationale and alternatives {#stated-rationale-and-alternatives}

Message chooses actual codec widths over misleading ItemStackNetIdVariant header spelling and uses one ItemStackRequestCereal body because scoped duplicates are identical. For serverbound autocraft, follows Cloudburst read rather than its inconsistent count-writing branch. Obsolete cases really rejected by BDS are retained as schema placeholders, an admitted compromise.
