# 82. feat(protocol): project the item stack net id onto one varint at 2168 {#82-feat-protocol-project-the-item-stack-net-id-onto-one-varint-at-2168}

Source: [ae447e6311b59ee95fb4dca88dd042c1d26b6962](https://github.com/EndstoneMC/bedrock-protocol/commit/ae447e6311b59ee95fb4dca88dd042c1d26b6962)

## Problem and constraints {#problem-and-constraints}

At2168 the optional net-id tagged union becomes one signed integer with semantic alternatives encoded in sign and parity.

## Implementation and producer semantics {#implementation-and-producer-semantics}

Redeclare SerializedNetworkItemStackDescriptor: optional varint32 replaces optional ItemStackNetIdVariant, dropping the explicit tag. Nonnegative=net id, negative odd=request id, negative even=legacy request id. Keep alias/type available because the binding, not all uses of the type, retired. Transitive dependency changes version packets30/32/49; old tests pin v1001 names.

## Stated rationale and alternatives {#stated-rationale-and-alternatives}

A one-field wrapper would restore no discriminated meaning; a tagged union would reintroduce the removed byte. The semantic mapping is placed in the docstring for downstream consumers.

## Tests and outcomes {#tests-and-outcomes}

Cloudburst-attributed armor/content goldens; no-id equality, 9 and -3 zigzag payloads, engaged-id length minus1, wrong-era misread and rejection. Packet30 engaged-id test is structural because Cloudburst still has pre-cereal shape.

These are tests and outcome claims examined in source. No upstream test, compiler, codec, regeneration, Windows or BDS execution was performed by this review. The cited source/byte checks are static observations, not independent runtime validation.
