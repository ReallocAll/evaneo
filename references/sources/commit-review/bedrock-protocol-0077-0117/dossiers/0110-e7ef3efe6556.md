## Problem and constraints {#problem-and-constraints}

PEP8 enum identifiers cannot encode BDS separator-sensitive wire names, and previous separate reflection/write tables disagree.

## Implementation and producer semantics {#implementation-and-producer-semantics}

Plain Enum accepts value/wire-string pairs; IntEnum/IntFlag/StrEnum require value(number,string,...) escape. Parser recognizes all four enum bases, rejects malformed/nonliteral/empty strings and invalid pairs. Reflected names_v now carries wire name; write calls enum_name; read keeps lowercased unordered_map and compiler rejects lowercase collisions per snapshot.

## Stated rationale and alternatives {#stated-rationale-and-alternatives}

Keep DSL syntax Python-like and nonexecuting griffe import from silently accepting invalid tuples. Read remains dedicated map because reflection is public API and scanning hundreds of case-folded names is undesirable. Wire names fallback to member names.
