## Evidence-weighted conclusions {#evidence-weighted-conclusions}

Supported, bounded inference: this history repeatedly revises implementation when protocol-reference mismatches, platform differences or unnecessary API machinery become explicit. Shared logic is extracted where duplicate counters/predicates could diverge. Tests, type checking and CI are expanded, then reorganized. These are repository-specific patterns with AI assistance and several counterexamples.

Unsupported generalizations: the subject always prefers rewrites, every test refactor preserves behavior, all data structures are bounded, all library errors share one hierarchy, synchronous send proves delivery, all lifecycle paths clean up, C++ compatibility is complete, or declared coverage equals independently validated correctness. This dossier intentionally supplies the counterevidence a retrieval system needs alongside the positive mechanism.

No independent lesson is claimed for pure whitespace, ignore-list updates, narrow repr formatting or unused-helper deletion. Their public provenance remains in the bundled commit notes, but these mechanical edits are not elevated into separate behavioral rules. The source analysis did not run upstream code; retrieval matches alone are not runtime validation.
