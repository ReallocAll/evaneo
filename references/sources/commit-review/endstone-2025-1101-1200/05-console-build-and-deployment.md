# Console takeover and build/deployment revisions {#console-takeover-and-build-deployment-revisions}

## From replacement reader to native-object reuse {#from-replacement-reader-to-native-object-reuse}
1156adds replxx.1158introduces a skeletal derived console reader and sets native stdin EOF so the original input thread exits.1170implements a process singleton with history and log output above the prompt; the sink now constructs one colored message rather than interleaving separate writes.1171distinguishes blank input from EOF/Ctrl-C and turns EOF into a queued stop command. It also delays accepting commands until after ServerLoadEvent.

1180–1182replace stream-flag-only suppression with explicit saved-descriptor redirection to NUL or /dev/null and later restoration. The first Windows attempt additionally manipulates the OS standard handle, then removes that layer. Descriptor operations are unchecked and non-RAII; startup exceptions or repeated calls are not proven clean.1184stops deleting/replacing the native reader through a nonvirtual base. Instead startEndstone joins its existing thread and starts a new loop on the same object, preserving native ownership/layout. Restoration clears both C++ flags and C FILE error state.

The final loop ignores empty lines, uses a SPSC queue and exits after stop/EOF. It ignores try_enqueue's failure result, so full-queue command loss, including stop, remains possible. Flag changes do not themselves unblock a blocked read. Restoring stdin before joining assumes the native reader already observed EOF. None of these races or shutdown paths was executed.

## Deployment escape hatch and tradeoffs {#deployment-escape-hatch-and-tradeoffs}
1183adds --no-interactive, ENDSTONE_NO_INTERACTIVE and explicit Pterodactyl environment detection for backward compatibility. Plain getline/stdout is the fallback.1184removes the tty requirement from interactive selection, so the final main choice depends on the environment flag rather than tty detection. The fallback's post-getline good() test can reject a final unterminated EOF line. The replxx printf precision call passes size_t after previously casting to int; this remains a static varargs type concern.

1186and1192suppress all Database messages at priority<=Info, with an exact repeated logger patch between main/release. This reduces automatic-compaction noise but is broader than matching one message; warning/error logging remains outside that filter. It is a signal/noise tradeoff, not evidence that low-priority database logs never matter.

## Dependency/build changes {#dependency-build-changes}
1165moves dependency setup to third_party and replaces Detours submodule acquisition with a commit-pinned archive; source lists/compiler options remain.1166updates CMake extraction policy/MakeAvailable.1196cherry-picks the earlier migration onto release, explicitly retaining conflict history and adding pybind11 discovery, but does not import1166's follow-on. Five file patches are exact duplicates. Detours internal changes from the1135gitlink bump are not audited; no download/configuration/build is run.

1157separates core pybind headers from runtime embedding linkage.1167–1168add clang-tools consistently to CI/coverage/Docker/wheel setup. Docker revisions1169→1172→1175first move base/final tobookworm, then return the builder tobullseye and finally usebookworm for runtime only. CMake/ninja move from a pinned shell installer to pip packages. Preserve this revision sequence rather than claiming a settled universal base-image preference. FUNCHOOK_BUILD_TESTS remains off: reduced build cost comes with dependency-test coverage delegated elsewhere, not automatic evidence of poor engineering. Existing project build/test commands are source content only.
