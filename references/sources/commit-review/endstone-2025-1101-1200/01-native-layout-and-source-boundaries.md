# Native layouts, concurrency primitives and runtime boundaries {#native-layouts-concurrency-primitives-and-runtime-boundaries}

## Problem and causal sequence {#problem-and-causal-sequence}
Endstone calls and hooks a proprietary native server. Compatibility is therefore more than a version constant: virtual slots, object size, enum ordinals, callback members and direct symbol addresses all matter. Commit1104 imports the complete PR286 port for1.21.120. Its exact PR base equals the target parent, PR head tree equals the target tree, and canonical full patch is identical. The earlier37-file semantic dossier is copied under context; this is verified reuse, not a conclusion from the PR title.

The port changes packet-size checking to a virtual limit with a10MiB default and strict greater-than rejection, adds entity-registry pre/post callbacks and network session publisher state, revises pack settings and native block layout, and renames native command permission mutation. The widened BlockChangeContext is a variant carrying environment/actor/script-command origin. Several additions model declarations/layout only. Generic forwarding wrappers and enum changes should not be treated as runtime-tested merely because source assertions compile elsewhere. The subsequent ChunkSource slot correction1109 follows a reported getLoadedChunks crash, showing that a broad port and a targeted vtable repair are separate evidence.

1115models Minecraft's IEntityRegistryOwner base.1120–1125prepare DedicatedServer/AppIsland ownership and a console reader with a native-looking SPSC queue. The queue uses a block ring, cached producer/consumer positions, relaxed atomics and explicit fences; its SPSC and no-concurrent-move assumptions are material.1122's member typo is fixed1123. The source explicitly credits Cameron Desrochers and Jeff Preshing; these are adapted upstream mechanisms, not evidence of algorithm invention by Vincent. Allocation failure, throwing element construction, debug-only omitted guard references and blocking-reader teardown remain static audit questions. No formal concurrency proof or stress test is claimed.

1176–1179then move platform/process lookup and hooking into internal runtime namespaces. Most edits are moves/qualification changes, but invalid GameMode conversion changes from throwing to returning WorldDefault. This exception matters: a refactor title is not proof of semantic equivalence. The native ServerScoreboard still relies on the native constructor installing the native vtable; its local placeholder virtual methods throw if reached.

1188updates the release symbol table for1.21.121. All65keys on each platform remain:48Windows and65Linux values change, with no added/removed keys or duplicate addresses. These checks establish table shape and preserved membership; they do not verify an address against a running BDS binary.

## Transfer and limits {#transfer-and-limits}
Useful when designing ABI port checklists, distinguishing layout declarations from implemented behavior, moving low-level platform boundaries, or auditing adapted concurrency code. Pair symbol-table checks with binary/version validation when execution is authorized. Do not infer a general preference for hand-rolled queues from this native-layout adaptation. The Detours gitlink advanced in1135and is later pinned in a download URL; the dependency's internal old→new delta was not captured. No external dependency implementation audit is silently implied.
