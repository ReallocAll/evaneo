# Player/world APIs and command exposure {#player-world-apis-and-command-exposure}

## Narrowing representation to observed domain needs {#narrowing-representation-to-observed-domain-needs}

[1538](https://github.com/EndstoneMC/endstone/commit/8d8c26adb048d8594b25b4c66ad7d4cd6446ffb2) explicitly removes plural/name-based level access in favor of a single server level. The message states the interface-simplification rationale; implementation replaces a map with one unique holder and updates actors, scoreboard enumeration, devtools, command origins, startup packets, weather-event lookup, Python and mock interfaces. This is a deliberate removal of speculative multiplicity, with real caller migration cost. It does not justify a timeless rule against generalization or prove that all possible future hosts have one level.

XUID illustrates staged representation repair. [1526](https://github.com/EndstoneMC/endstone/commit/7f926202c024ac04997ae0d17355d1d031f8faad) models certificate chains and relocates WebToken without content changes. [1527](https://github.com/EndstoneMC/endstone/commit/54cf080f3a2615276d29dcabdfe0a9c10ef321b8) exposes a uint64 cache initially left at zero. [1528](https://github.com/EndstoneMC/endstone/commit/c2e6ae0bcc7169722088f213e649391d6467a527) extracts a string from certificate extraData instead and changes both language APIs accordingly. The wrapper checks the identifier component, but relies on its certificate pointer and modeled flag rather than implementing certificate verification. The source is about extracting engine-provided identity, not establishing a new trust boundary.

[1552](https://github.com/EndstoneMC/endstone/commit/1663f546aba166aa3e425ff76e51c8297cadf429) similarly changes device ID from UUID to opaque string and removes UUID parsing. That avoids imposing a stronger format than the data needs. Together these are evidence for revising representations when native data semantics require it, with explicit counterexamples to treating the first API signature as settled. No external protocol specification was audited in this unit, and no sensitive real-player values were copied.

Player ping becomes integer milliseconds only in Python at [1518](https://github.com/EndstoneMC/endstone/commit/7d8689bc7635aef22fac4229f92592cdd5b84e25), while C++ retains chrono duration. Actor identity and liveness are added at [1505](https://github.com/EndstoneMC/endstone/commit/6dc04c39e5adc11f37d5fccb63c677743354ab44) and exposed at [1507](https://github.com/EndstoneMC/endstone/commit/443b66d506b38820afde39cd9b7d02375071e32d). isDead is implemented as !isAlive despite documentation describing marked-for-removal state. These differences matter when generating bindings or describing a public contract; documentation wording and implementation should not be merged uncritically.

## Commands: advertisement, grammar and native model {#commands-advertisement-grammar-and-native-model}

[1531](https://github.com/EndstoneMC/endstone/commit/3f5b825e758f77c0bb3aec1e53c46d29273f6b5d) enables enum autocomplete and resolves duplicate names by suffixing, with a warning and insertion check. It chooses coexistence over rejecting or merging colliding enum definitions. bool receives the same expansion option. [1532](https://github.com/EndstoneMC/endstone/commit/e5953377407221164b3b87a9b073113bacf43534) adds modeled flags and [1533](https://github.com/EndstoneMC/endstone/commit/73fa791e04d1af1aa444f1adfd52f0dc3481ee8e) fills a missing overload boolean, both native declaration work rather than independently implemented command behavior.

[1534](https://github.com/EndstoneMC/endstone/commit/46325a32420940cccb2dfe36bdde34f1929f1847) changes the outgoing command packet from hidden flags to actual erasure of unauthorized/unregistered/internal entries. This is materially different client advertisement. The patch also changes permission lookup ordering relative to lowercasing; that second hunk is preserved rather than explained away by the title. Neither hunk replaces execution-time authorization. A client not seeing a command and a server rejecting its invocation are separate checks.

[1535](https://github.com/EndstoneMC/endstone/commit/6c8ec8d716e48d66ec0ba6156388324610f0a565) removes one outer quote pair from Id tokens when constructing plugin arguments. It is deliberately narrow: unmatched quotes, short values and other grammar symbols are not transformed, and escapes are not decoded. The added command tutorial documents parameter forms and default permissions, but does not supply a regression test for these changes.

## Teleport: reuse of engine work versus event authority {#teleport-reuse-of-engine-work-versus-event-authority}

[1553](https://github.com/EndstoneMC/endstone/commit/6e50d5daa9f7f2a06f82f64fc22fe69da68ae686) adds PlayerTeleportEvent at the native Player teleport call, complementing the earlier actor event. It allows cancellation and passes edited destination coordinates to the original function. Although the event exposes a Location, edited dimension and angles are not applied by this hook, nor does changing from-location alter execution. Source consumers should not infer full authority from the richer event object.

[1554](https://github.com/EndstoneMC/endstone/commit/fbee581e3cf69b1def134106aa6db36264644b64) declares Actor::teleport and forwards it through Mob and Player, while implementation remains TODO. [1555](https://github.com/EndstoneMC/endstone/commit/671233ca321280ec25fd20cc6fd1a48e9ce7a318) supplies the call through native TeleportCommand computeTarget/applyTarget, with explicit position, optional destination dimension, absolute pitch/yaw, current command version and velocity preservation disabled. [1556](https://github.com/EndstoneMC/endstone/commit/c0d61fa86691447f4c025cca9efb056b7a4fbfca) supplies the actual hook bodies and both platform symbols. This observed design reuses the engine's command target construction rather than directly writing position. It is useful evidence for reusing native behavior where transformations are complex, but the unit has no cross-dimension execution result or Python teleport binding.

The distinction between the API entry path and the hook event remains important: using a command-based target can carry dimension/rotation data, while the event hook shown only substitutes XYZ. No claim about exactly which native internal calls fire in every teleport case is made without execution or additional engine source.

## Block scaffolding and limits of comments {#block-scaffolding-and-limits-of-comments}

[1549](https://github.com/EndstoneMC/endstone/commit/a0aa7ed72d6a987c98ac7230d688f5d59a3f2234) and [1550](https://github.com/EndstoneMC/endstone/commit/6860eb1139c93de13ade0a6ee0b3cc205f19c36d) introduce Block, BlockData and getBlockAt. [1551](https://github.com/EndstoneMC/endstone/commit/532489c1456525945f61a44c53d80eca1ee2f68e) allocates a wrapper containing a BlockSource reference and position, but getData still returns null. The Block comment promises one live object per location and mentions getState snapshots; the implementation creates a new wrapper on each call and does not expose the promised snapshot method here. This is a clear example where interface prose anticipates future work.

These commits therefore provide design intent and initial access scaffolding, not evidence of a finished block-state model. No tests are added for block identity, snapshot isolation or native source lifetime. Future synthesis should retain the incomplete status and wait for later canonical history before claiming the final abstraction.

## Attribution and applicability {#attribution-and-applicability}

All target commit identities are preserved and attributed from Git objects. This unit does not read PR/review discussions or independently attribute engine internals to the author. Native layout models and existing command/teleport facilities are dependency context. The useful outcomes are dated API evolution, explicit interface simplification, source-visible representation corrections, and carefully bounded event/advertisement authority. These can guide future research and validation without becoming assertions about current Endstone behavior.
