# Permission levels and packet-mediated interactions {#permission-levels-and-packet-mediated-interactions}


<a id="explicit-design-rationale"></a>
## Explicit design rationale {#explicit-design-rationale}

PR184's author states that Bukkit-like operator/nonoperator permission levels cannot express console-only administrative commands. The proposed 0.10 breaking migration replaces boolean permission parameters with Default, Operator and Console, removes unused ProxiedCommandSender, and documents Python migration. The final squash at820 is reused from the completed PR dossier only after base/head and exact old/new blobs and hunk identities match; merge repetitions retain separate occurrence records. A Codecov bot's “covered” claim alongside 0.00% project coverage is a captured report, not an executed test result.

The enum expresses a default permission tier, not an absolute security boundary: permission attachments still override defaults. Generic Permissible no longer mutates operator state; Player retains it. Native Host command gating is lowered only after Endstone permission checks, replacing the earlier conservative Host exclusion. Default sets become ordered vectors, and821 aligns Python stubs. The dirty-default recalculation only marks newly included levels; removal/reclassification cache behavior remains a boundary. No permission tests accompany this migration.

<a id="interaction-chronology"></a>
## Interaction chronology {#interaction-chronology}

828 adds Action and clicked_position contracts. 829 connects RightClickAir to native item-use events and replaces unsafe ItemInstance reinterpretation with an actual ItemStack copy before wrapping. RightClickBlock is adapted. 830 provides packet layout scaffolding, while831 intercepts StartDestroyBlock actions, deletes only cancelled entries, and calls the native handler afterwards. This changes the existing wrapper from native-first to wrapper-first, including the client-init join callback. With no resolved player, native handling is not forwarded.

At900, LeftClickBlock passes world coordinates while the documented clicked_position contract describes a 0–1 block-relative vector for RightClickBlock only. LeftClickAir is declared but has no dispatch site in the inspected endpoint. The broader887 changelog assertion must therefore be read as an authored release claim.832 adds ray-clipping parameters and public direction/vector utilities; borrowed endpoint references and zero normalization are not tested. Public std::numbers use also needs scrutiny against822's stated C++17 repair.

PR213 (killcerr, coauthored by Vincent and alternate killcerr email) extends the same pre-native packet mechanism to held-item changes. Cancellation sends the current slot back and suppresses the native handler. No same-slot, container or slot-range filter appears at that callback boundary.869 similarly moves emote handling away from a script notification so cancellation can actually stop downstream broadcast and mute can rewrite a packet flag; it skips server-side emotes and removes the old script dispatch to avoid duplicates.

## Costs and scope {#costs-and-scope}

Earlier interception offers control before native effects, but exposes plugin callbacks to data whose later native validation has not yet happened. Packet field/layout assumptions and synchronization responses were read, not exercised. Declared action/packet types are not evidence that every route is active. No packet integration test or runtime trace is claimed.
