# Command regressions, build workflow revisions and release boundaries {#command-regressions-build-workflow-revisions-and-release-boundaries}

<a id="reproduction-and-tests-are-distinct-from-a-fix"></a>
## Reproduction and tests are distinct from a fix {#reproduction-and-tests-are-distinct-from-a-fix}

Issue190's author Arduinonk reports `/ban` truncating quoted multiword names on0.8.1. Vincent identifies PR180 as the regression and links endstone-test commit2361546b2cd3ff1e0b7a3816b128e5a294b1c8e1. The linked regression tests cover API-created bans and quoted unban commands: tests bridge API-created bans to quoted unban commands and quoted ban/reason commands to API cleanup, asserting actual name/reason state. They do not merely test a command return value. Fixed synthetic names and inline cleanup can leave a ban if an assertion fails. There is no run result in the captured discussion or this review.

714 changes dispatch to find the native signature, create/register a fresh MinecraftCommandWrapper and execute through it, rather than looking up an existing wrapper.735 backports the dispatch change.715's ParseToken formatter becomes structured diagnostic text but lacks JSON escaping; unsupported command output types stop throwing. That same commit changes a Detours gitlink;716 immediately restores it. Keep that dependency reversal separate from the formatter rationale, which does not explain the pin change.

Issue185 provides a second concrete constraint: config/default/permissions.json loses an added server-net module when the updater overwrites it. SuperEric1 corroborates Arduinonk's report; Vincent reports a fix.733 backports default-preserve extraction with explicit overwrite patterns for executable and shipped assets. The skip condition also disables later server-property modification whenever any existing preserved file is encountered. No updater archive or installed server was modified here.

## Parallel branches and the release process {#parallel-branches-and-the-release-process}

Chronological order is not a single linear main branch.730–749 contain stable backports and releases;750 merges seventeen reviewed branch ancestors. Its __init__ resolution combines main's ItemRegistry exports with stable's1.21.84 version. The symbols table adopts the stable blob wholesale, temporarily losing main-only hooks until751 restores them. The port revert is stable-only. The audit proves these distinctions through trees, parents and exact hunks, rather than treating a revert title as the repository-wide final state.

741/742 initially remove main push CI while adding explicit PR event triggers and per-ref cancellation.744/745 restore main/stable/v* pushes, make published releases the publication trigger and narrow wheel/portable permissions.747/748 narrow Docker triggers to main push, daily schedule and published release. The endpoint docs workflow already has a published-release trigger matching its revised deployment condition. These are workload/publication choices; no CI run, timing benefit or registry publication is claimed.730 repairs post-container Conan ownership;731 uses OS/SHA cache keys with OS-prefix restore.

757 uses the pybind11_stubgen API and a composed parser instead of the CLI subprocess. This allows focused enum/typing customization but couples to parser internals; the generator was not run.761 refreshes Windows runners.762 changes original-hook lookup from hashed names to executable-base+compile-time symbol RVA and actual target-pointer keys, tightening name membership while leaving runtime lifecycle assumptions intact.
