# Native ports, shutdown and Python lifetime {#native-ports-shutdown-and-python-lifetime}

<a id="porting-and-lifecycle-are-interleaved"></a>
## Porting and lifecycle are interleaved {#porting-and-lifecycle-are-interleaved}

PR272/1035 targets BDS1.21.111 and protocol844 despite its1.21.110 title. It changes native actor/player/level/resource/auth/packet declarations and ownership shapes. It also removes teardown from the script-manager reset hook and installs a static server-thread-stopped listener that disables plugins and resets the server locator. That narrows teardown to a server-stop event. It does not make resource reload safe for every in-flight callback.

The public issue219 report is specific: a Script API command triggers reload_data while its callback still needs to return. Vincent explains that rebuilding the script command registry invalidates the in-flight callback; a native scriptevent command differs. This explanation is explicit evidence. A claim that the new stop listener fully fixes that issue would exceed the code and discussion.

1035 temporarily disables custom resource-pack hooks/loading.1036 introduces repository source creation hooks but has an intermediate return-type/order mismatch.1037 repairs the signature, stores the borrowed repository before native creation can invoke initialization, adds symbols and re-enables loading.1039 supplies a default destructor. The meaningful chain is disable → reconstruct boundary → repair call order/signature → re-enable, with native pack behavior unexecuted.

## Native ABI evidence is bounded {#native-abi-evidence-is-bounded}

1043 removes obsolete BlockType fields and adjusts offsets after a block-inventory report.1047/1050/1074 rewrite symbol addresses for new BDS revisions. Entire tables are parsed and keys compared; additions/removals receive semantic review.1055 loses ActorFactory keys and1056 restores them.1075 loses the old map-update hook key before1077 deliberately removes that hook. Structural checks prevent these exceptions being hidden in large numeric churn, but do not establish binary compatibility.

1041 accepts skin byte buffers by bounded copy/padding rather than throwing on size mismatch, and removes the old token/base64 skin parser. This closes a previously identified source route; it is not evidence that every image format is converted or every native skin is valid.

## Object retention and asynchronous work {#object-retention-and-asynchronous-work}

1093 moves Plugin, CommandExecutor and MapRenderer trampolines to py::smart_holder with trampoline_self_life_support. The explicit goal is safe Python-to-C++ object passing. Removing manual keep_alive requires checking actual C++ owners; borrowed maps/commands are not made independently immortal.

1097 adds a lazy daemon asyncio thread with thread-safe submission. Its internal shutdown cancels/gathers tasks, closes async generators/default executor, stops/joins/closes the loop. The source has no public shutdown export or loader/server integration. `fut.result()` is unbounded by join_timeout, self-thread shutdown can wait on itself, and submission occurs after releasing initialization locking. Endpoint reload still has an async-quiescence TODO. These are source-level constraints, not observed crashes or deadlocks. They should guide later lifecycle review rather than be flattened into a blanket safety verdict.
