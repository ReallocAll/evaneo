# Command isolation, chat, deployment and diagnostics {#command-isolation-chat-deployment-and-diagnostics}

<a id="a-malformed-command-can-affect-other-commands"></a>
## A malformed command can affect other commands {#a-malformed-command-can-affect-other-commands}

PrimeStrat's issue255 initially looks like a message lexer problem. Vincent requests plugin-free reproduction and a narrowed custom command. The reporter identifies a message argument followed by optional duration fields and reports that reload does not recover the parser. Vincent explains that message must be last, including before optional arguments, because native registration can disrupt other message-taking commands. Issue258 converts that diagnosis into a registration-validation requirement.1007 adds the rejection. This is a useful concrete investigation sequence: narrow cross-command symptoms to a registration contract rather than patch every failing command. It does not demonstrate native parser recovery after corruption.

<a id="chat-semantics-are-branch-sensitive"></a>
## Chat semantics are branch-sensitive {#chat-semantics-are-branch-sensitive}

1001 merges differing main/release APIs;1010 cherry-picks chat formatting support and carries stub effects.1011 reconstructs a TextPacket when the message changes, preserves selected packet metadata, and cancels the original route. A format-only change follows raw-send routing. The recipients getter returns a vector copy, so reference_internal does not turn Python list edits into event mutation. A player-only edit is no longer sufficient to select the changed-message branch. These contracts come from actual code; the PR254 body supplies no rationale.

1013 replaces a manual client inventory update workaround with explicit invalid network-ID state. Issue242 distinguishes author intent (set_item should immediately update the slot) from a reporter's observed need to drop the item. The linked CI build was not opened or run.

## Deployment and logging costs {#deployment-and-logging-costs}

1004's container starts as root to recursively chown the existing server directory and then execs gosu as UID1001. This repairs mounted ownership at the cost of startup traversal and changed file ownership; it is not a general recommendation to run the server as root.1008 allows Windows startup to continue if loopback exemption fails, but the warning retains a stray %s.1083 warns on Store Python without aborting;1084 adds colorlog;1085 adapts these into main's relocated CLI.

1060 moves the native logging detour to LogDetails::_log_va and sends ResultLogger failures directly to cerr.1099/1100 upgrade cpptrace and delegate formatting to object-address/basename/snippet settings. These changes reduce custom formatting and alter displayed evidence, without validating crash signal-safety or Sentry reporting.

No Docker image, Windows launcher, native logger, packet path, crash handler or external dependency was executed. Reports and code intentions are separately identified in the per-commit entries below.
