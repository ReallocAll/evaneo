# Python package and generated contract evolution {#python-package-and-generated-contract-evolution}

<a id="package-change-is-a-coordinated-boundary-change"></a>
## Package change is a coordinated boundary change {#package-change-is-a-coordinated-boundary-change}

1022 migrates21 bound enums to pybind3 native enums.1023/PR263 changes the compiled module to `_python`, creates native submodules and lazy public facade packages, relocates CLI/plugin/metrics/version files, installs runtime artifacts at the package root, and adds py.typed/lazy-loader. These are coupled changes across CMake, imports, wheel layout and Python API, not merely a directory move. Nine move pairs are checked explicitly; four are byte-identical and five contain read residual changes. The same PR removes Position, makes Vector a float type, and restores optional Scoreboard objective display names after1022 temporarily required a string.

Plugin identity1025 comes from normalized entry-point name rather than a class override. The explicit unique-identifier rationale does not prove collision freedom: hyphen-to-underscore normalization can still conflate names. Main's package contract remains distinct from the release branch, whose monolithic stubs and NamespacedKey API persist. Merge residuals retain this distinction.

## Why generated output is not counted by size {#why-generated-output-is-not-counted-by-size}

The initial pybind11_stubgen output broadens numeric annotations and emits enum boilerplate.1028 narrows protocols back to practical primitive/list forms.1045 introduces a custom Griffe/Jinja generator with explicit support for binary submodules, property models, native enum values, signature/docstring extraction, imports/exports and ordering.1046 repairs self annotations;1057 injects Python wrapper members and handles parameter-kind transitions;1058 fixes enum member annotations;1059 removes the old driver;1088 expands ruff checks.

All meaningful generator implementation was read. Large stub deltas have exact AST/member identities, complete transformation group membership and separately audited comments/standalone documentation. This is verified structural reuse, not a title/path shortcut.1057's211 distinct residuals include real public-contract changes: Plugin's declared base disappears, wrapper fields appear, event_handler gains a None result annotation, public imports replace private qualification, enum values become assignments, and Dimension actor methods appear.

## Failure and contract boundaries {#failure-and-contract-boundaries}

Signature parsing warns and falls back to variadics; import collisions warn; ruff subprocess failures are printed without becoming a hard failure. Property models contain deleters that the template does not render. Generated source can therefore remain incomplete even when the driver reaches its final message. Nullable native lookup returns also remain annotated as nonoptional in several stubs. No generator, Python extension, type checker or wheel was run.

1071's new helper documentation claims packaged config defaults and separator normalization beyond the visible implementation. The ledger preserves authored documentation as intent and compares it with code instead of silently treating it as a tested contract. The completed PR263 dossier has an empty body and no human rationale/review; architectural motivation beyond the observed changes is inference.
