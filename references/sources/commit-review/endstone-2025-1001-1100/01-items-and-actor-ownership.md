# Item values, registries and actor ownership {#item-values-registries-and-actor-ownership}

## Decision chain {#decision-chain}

The incoming history has two incompatible branches: main already exposes string item IDs, while v0.10 retains ItemType-based APIs. Commit1001 integrates the release's corrected native count setter with main's string contract. Later1015 makes the native adapter hold an ItemInstance by value;1017/1032 preserve main's string/Result API while merging release repairs. This changes the clone question from borrowed-handle aliasing to the actual native copy constructor. The endpoint constructor clones NBT and copies selected native state, so the old aliasing claim no longer applies to this adapter. It is still not a demonstrated round-trip identity for every native field.

1018 makes construction/type/amount validation explicit via Result, including amount1–255 and unknown-name rejection. Python construction converts failure to an exception, while its property setter discards the Result. Endpoint1100 still calls empty native reinit overloads for type mutation. Thus successful validation is not proof that a native item changed type. Strong `item && *item` checks in1030/1032 distinguish metadata-bearing nonnull stacks from a valid Item pointer;1031's isNull semantics explain why that distinction matters.

Registry reconstruction at setLevel/reloadData (1019) replaces the registry objects. Returned registry entries are borrowed. No source evidence here establishes that previously retained Python/C++ entry references survive reconstruction.

<a id="metadata-redesign-and-preservation-cost"></a>
## Metadata redesign and preservation cost {#metadata-redesign-and-preservation-cost}

PR215 first adds map metadata through concrete implementation classes and forwarding.1070 moves common state into public ItemMeta and a final MapMeta. Template specializations handle native serialization, equality and applicability. This removes the diamond/holder complexity and makes ordinary values self-contained, but enchantment validation still consults the server registry.

Nonempty metadata writes now clone existing NBT and rewrite known fields, preserving unrelated tags. Empty/null metadata remains a full user-data clear. Equality fixes an old self/self argument but drops the map-only `notUncommon` restriction: a generic meta and map meta with identical common fields can compare equal regardless of map-only state. The inverted MapMeta emptiness predicate introduced1070 is corrected1089. Neither the redesign nor its correction adds focused NBT/equality tests in this range.

## Actor ownership {#actor-ownership}

1050 adds spawnActor/getActors and move-only OwnerPtr<EntityContext> transfer into the dimension. Moving resets the old context; destruction releases the registry entity. This is an explicit ownership transition, not a reason to treat returned Actor wrappers as owning. Python spawn_actor's default return policy deserves separate lifetime scrutiny; the source alone cannot validate it.

The initial identifier parser mishandles names without event suffixes and reinitialization.1052 clears canonical/hash cache state and adds eight focused parser tests. These tests are materially stronger contract evidence than native offset assertions, but were not executed here.

## Use and limits {#use-and-limits}

Use this chain when reviewing value-versus-borrowed adapters, Result propagation across bindings, registry refresh invalidation, known-versus-unknown NBT preservation, and native ownership transfer. Do not infer broad preference for public data objects or claim tested native mutation from these commits. Actual author is Vincent; relevant issue reporters and prior PR authorship remain separately attributed in the thread/commit ledgers.
