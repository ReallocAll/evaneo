## Decision and context {#decision-and-context}

Restore nested classes/enums with scope-aware resolution and stable cross-snapshot identity.

## Observed implementation, tests, and changes {#observed-implementation-tests-and-changes}

Importer recursively registers dotted paths; Parser.lookup searches inner-to-outer scopes and module scope, predicates can reference qualified nested enum members, and nested identical redeclarations collapse. Struct metadata carries nested descriptors, dependencies and change points. Snapshot projection recursively filters children. Backend emits C++ scope names, nested definitions/aliases, reflection and serializer specializations innermost-first. A scope-only owner with nesting but no fields has no serializer; an empty leaf still can be a zero-byte variant alternative. Unchanged nested types anchor to the first owner snapshot to avoid duplicate C++ types.

## Rationale and alternatives {#rationale-and-alternatives}

Explicit: mirror BDS nesting without forcing unrelated owner snapshots to redefine identical child types. Keep dependency/topology/include planning at outermost root while names remain scoped.

## Constraints, revisions, and uncertainty {#constraints-revisions-and-uncertainty}

No new tests in this compiler patch; schema/test exercise follows [#65](0065-203095993612.md). The implementation's anchoring groups all nested children based on whether any changes, which is a conservative strategy, not minimal dedup per child. Recursive names do not prove every alias cycle or redeclaration-inside-one-body case works.
