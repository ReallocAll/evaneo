## Decision and context {#decision-and-context}

Make aliases over versioned types snapshot-aware without duplicate serializer specialization.

## Observed implementation, tests, and changes {#observed-implementation-tests-and-changes}

FileGenerator detects aliases whose referenced roots are versioned, emits namespace aliases, public selectors and latest aliases, and generates variant serializers with the relevant snapshot context. _alias_plan skips snapshots with missing referenced types and keys concrete identity by fully spelled C++ target so unchanged aliases reuse a prior definition.

## Rationale and alternatives {#rationale-and-alternatives}

Explicit: using names an existing type rather than creating one; emitting a Serializer for each alias spelling would redefine the same specialization. Existing-output identity is reported while enabling the upcoming pre-cereal transaction variant.

## Constraints, revisions, and uncertainty {#constraints-revisions-and-uncertainty}
