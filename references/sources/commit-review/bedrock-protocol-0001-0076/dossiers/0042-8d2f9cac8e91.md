## Decision and context {#decision-and-context}

Support optional containers correctly and temporarily encode cereal dynamic-member markers through nested Optional syntax.

## Observed implementation, tests, and changes {#observed-implementation-tests-and-changes}

Optional decoding stages an inner typed value before assigning the optional, allowing vector/map member operations; serialize parenthesizes dereference. Optional[Optional[T]] collapses to one std::optional in C++, while a PresenceWrapperGenerator writes true then delegates the actual optional. Decoder only checks marker read success, ignores false value. Parser adds explicit Optional[...] syntax because unions flatten nesting.

## Rationale and alternatives {#rationale-and-alternatives}

Explicit: cereal composite-member traversal emits an always-present metadata marker in addition to actual value presence. The model retains a simpler user-facing optional.

## Constraints, revisions, and uncertainty {#constraints-revisions-and-uncertainty}

False marker is not rejected and may cause remaining bytes to be misinterpreted. [#76](0076-e38efb023954.md) replaces this special case with explicit Literal[True], removes nested-optional syntax and validates the marker. Do not teach this intermediate encoding as the final design.
