## Decision and context {#decision-and-context}

Resolve auto-numbered enum sentinels after snapshot filtering.

## Observed implementation, tests, and changes {#observed-implementation-tests-and-changes}

EnumValue records is_auto. _renumber walks present values using previous+1, leaving explicit numbers fixed; _snapshot_view uses the result in identity keys. Sound UNDEFINED becomes auto(), yielding601 at the old snapshot and611 at1001.

## Rationale and alternatives {#rationale-and-alternatives}

Explicit: a count/end sentinel belongs to its own snapshot's visible members, not the unfiltered aggregate.

## Constraints, revisions, and uncertainty {#constraints-revisions-and-uncertainty}

This is previous-value-plus-one, not the number of members when enums are sparse. _is_auto also recognizes value() without positional args, but the existing _enum_number still rejects that spelling; the exercised change is auto(), so do not claim optional-number value() works.
