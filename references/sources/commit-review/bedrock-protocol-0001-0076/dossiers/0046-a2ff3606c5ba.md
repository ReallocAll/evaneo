## Decision and context {#decision-and-context}

Separate primitive storage type from its field-specific wire codec.

## Observed implementation, tests, and changes {#observed-implementation-tests-and-changes}

PrimitiveType gains wire and encoding property; parser applies field(type=) to integer primitives and primitive aliases, rejecting noninteger conversions. C++ read/write helpers and include analysis use encoding, while cpp_type still keeps original type/alias. Previously such overrides on primitives were silently ignored.

## Rationale and alternatives {#rationale-and-alternatives}

Explicit case: ContainerID is a signed-char semantic type but legacy packets write it as signed varint32. Preserve both memory identity and wire encoding instead of replacing the type.

## Constraints, revisions, and uncertainty {#constraints-revisions-and-uncertainty}

The patch constrains both sides to integers but does not add checked narrowing/range validation; reading a wider value into a smaller representation may still narrow. Nonprimitive TypeAlias targets do not receive this new override mechanism.
