## Decision and context {#decision-and-context}

Recover pre-cereal InventoryTransaction by redeclaring four changed types and letting versioning propagate through unchanged wrappers.

## Observed implementation, tests, and changes {#observed-implementation-tests-and-changes}

Legacy items use varint ID and early-out when ID0, then conditional stack/aux/optional plain net ID/signed block ID/blob. Legacy InventorySource is a switch with signed-varint container IDs and world-interaction flags, not optionals. Legacy transactions have bare action lists; ItemUse face uses signed varint while predicted result is explicitly unsigned varint. Packet30 conditionally writes legacy slots only for nonzero request and uses a bare variant. Four old-version goldens cover empty Normal, container action, ItemUse and nonzero legacy slots.

## Rationale and alternatives {#rationale-and-alternatives}

The message uses historical gophertunnel and BDS-era information to recover wire behavior absent from cereal dumps. Unchanged InventoryAction and variant wrapper types inherit versioning through references rather than duplicated gates.
