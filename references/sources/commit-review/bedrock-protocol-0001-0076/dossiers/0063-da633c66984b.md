## Decision and context {#decision-and-context}

Generate enum reflection tables from already-known declarations instead of compiler-signature introspection.

## Observed implementation, tests, and changes {#observed-implementation-tests-and-changes}

Adds enum.hpp with empty primary values/names/type-name arrays and generated specializations per fresh snapshot. constexpr API provides names, values, entries, counts, casts, contains, index and underlying conversion; reflected-only operations have requires constraints. Lookups are linear; runtime enum_value index is unchecked. Declaration order is preserved, so no min/max API. Tests cover negative sentinel, holes, case-sensitive name lookup and snapshot member sets.

## Rationale and alternatives {#rationale-and-alternatives}

Explicit magic_enum analogy: generation already knows the domain, avoiding PRETTY_FUNCTION parsing and bounded-range sparse/flags/hash machinery. Names/semantics track the familiar API while documented order differs.
