## Decision and context {#decision-and-context}

Add the cereal-era InventoryTransaction packet and its entire reachable item/source/transaction closure.

## Observed implementation, tests, and changes {#observed-implementation-tests-and-changes}

Packet30 since1001 carries legacy request, optional legacy slots and optional five-case transaction variant. Items have fixed int16 ID, fixed uint16 stack size, optional three-case network-ID variant, compressed block ID and opaque length-prefixed extra-data bytes. Source container and flags use the double-marker optional adapter. Actions are themselves optional lists. Three fixtures exercise empty Normal, a container action with stone/air, and ItemUse; each decode checks unread length and key fields.

## Rationale and alternatives {#rationale-and-alternatives}

Explicit opaque-data boundary: NBT/can-place/can-break/shield data already travel in one blob, so model that carrier rather than prematurely expanding it. Dynamic marker evidence is attributed to BDS disassembly in the message.
