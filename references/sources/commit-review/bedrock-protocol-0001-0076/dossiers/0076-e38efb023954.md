## Decision and context {#decision-and-context}

Replace a magical nested-optional adapter with explicit validated wire constants.

## Observed implementation, tests, and changes {#observed-implementation-tests-and-changes}

LiteralType carries homogeneous bool or integer values and a primitive wire codec. Booleans default one-byte; integer literals require explicit integer type. Generator omits C++ members, writes first accepted literal and rejects other decoded values with illegal_byte_sequence. InventorySource spells two Literal[True] markers followed by ordinary optionals. Removes explicit Optional[...] parser and PresenceWrapperGenerator. New malformed-fixture test flips first marker byte7 tofalse and expects rejection.

## Rationale and alternatives {#rationale-and-alternatives}

Explicit: the previous adapter consumed but did not validate a false marker, risking stream misalignment. Literal models a fixed wire obligation directly while leaving the public C++ struct unchanged; the reported generated source delta is two validation branches.

Keep nested optional and silently ignore marker, add an exposed marker field, or use a reusable wire-only constant node. The chosen node makes the wire grammar visible without leaking protocol boilerplate into consumer memory.

## Constraints, revisions, and uncertainty {#constraints-revisions-and-uncertainty}

This parser accepts top-level Literal fields; arbitrary nested container/conditional-literal composition is not established. Integer range checks against chosen widths are not added. The marker test covers the first marker, not every malformed literal or noncanonical bool representation. All runtime results remain historical reports.
