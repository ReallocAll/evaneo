## Decision and context {#decision-and-context}

Replace broad scaffold with a smaller protoc-shaped MVP rather than carrying unsupported feature branches.

## Observed implementation, tests, and changes {#observed-implementation-tests-and-changes}

15 files change; 796 additions/3032 deletions. Central SerializerGenerator walkers, StructGenerator, validate.py and extensions.py disappear. A MessageGenerator delegates primitive/enum/message/optional/repeated/variant nodes to polymorphic FieldGenerators built by a factory; Printer now supports variable substitution and explicit indentation. Parser/descriptor/resolver drop nested/versioned enum, predicates, map/bitset, count/tag/endian/trailing and builtin machinery. Header/source separation, name-coded enum codec, version selectors and transitive resolver remain. Code still silently skips unknown enum values and emits empty structs for unresolved fields; later concrete cases expose these.

## Rationale and alternatives {#rationale-and-alternatives}

Message explicitly adapts protoc architecture and implements only the MVP-required feature set, reporting about 4500 to 2300 lines, goldens 3/3 and downstream 6/6. These are historical author reports, not runs here. Removing a feature is not a lasting dislike of that feature: many are re-added with packet demand.

The removed broad framework is the actual prior alternative. [#32](0032-1322a8a143f0.md)/[#33](0033-5f80951e03aa.md)/[#34](0034-a300a054db52.md) refine ownership and boundaries further; [#34](0034-a300a054db52.md) reverses the terminology change in [#4](0004-89a9452ce7e2.md).
