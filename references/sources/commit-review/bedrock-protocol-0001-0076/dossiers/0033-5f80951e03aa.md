## Decision and context {#decision-and-context}

Split file access, graph loading and one-file parsing along protoc-shaped interfaces.

## Observed implementation, tests, and changes {#observed-implementation-tests-and-changes}

SourceTree opens static griffe modules with allow_inspection=False and collects all class redeclarations. Importer loads requested roots, parent packages, version module and transitive imports, classifies global symbols/aliases, then passes explicit module/declaration/import data to Parser. SymbolTable replaces _ClassifyResult; Parser no longer opens files. CLI uses Importer(SourceTree()).load_all then DescriptorPool.

## Rationale and alternatives {#rationale-and-alternatives}

Explicit divergence: references resolve eagerly during parsing, unlike protoc's later DescriptorBuilder, so all modules must be loaded and classified before parsing. The separation names that constraint rather than pretending full protoc equivalence.

## Constraints, revisions, and uncertainty {#constraints-revisions-and-uncertainty}

Code reorganizes prior logic and the message reports identical generated outputs. That is historical evidence, not a fresh run. Global unqualified symbol names and alias declaration-order resolution remain limitations.
