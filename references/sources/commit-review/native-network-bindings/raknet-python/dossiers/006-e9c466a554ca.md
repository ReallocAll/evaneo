## Engineering finding {#engineering-finding}

The design defines Peer, Connection, factories, context managers, builtin timeouts and explicit close exceptions over the raw binding. One daemon receive pump per peer routes into lock-protected connection/pending maps and condition-variable mailboxes. Mailboxes drain queued data before raising a sticky close result. The initial send path prepends ID_USER_PACKET_ENUM and the router strips it;017 reverses that wire policy. A sole-pending-request fallback can associate a response without checking its endpoint;014 replaces it. Close joins the pump, shuts down the native peer and wakes connect/ping/accept waiters. Loopback tests cover echo, pong, rejection, timeouts, close and poll. raw.py reuses the original top-level binding exports. The design is preparatory intent, not third-party review feedback.
