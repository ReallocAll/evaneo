## Engineering finding {#engineering-finding}

Adds optional max_queue, default None. Sync mailbox capacity is checked under its Condition; async uses a soft counter shared by pump and loop, with an explicit comment tolerating a small race. Overflow removes the connection, notifies native close and eventually raises ConnectionClosedError after queued data drains. The limit counts messages rather than bytes, and zero/negative values are not validated. The first overflow test races its reader against delivery;027 fixes that test ordering.
