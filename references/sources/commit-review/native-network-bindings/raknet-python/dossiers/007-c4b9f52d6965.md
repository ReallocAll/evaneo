## Engineering finding {#engineering-finding}

Shared startup/finish/close hooks allow an asyncio subclass to receive pump notifications through loop.call_soon_threadsafe. Async receive relies on asyncio cancellation; connect abandons a pending native attempt when cancelled after startup, and the factory closes the peer on BaseException. Close offloads pump joining and native shutdown with to_thread. Factories initially construct inline;018 moves startup off the loop. Tests cover echo, pong, rejection, close, receive timeout and concurrent clients. The to_thread startup await occurs before cancellation cleanup begins, so cancellation at that boundary can leave work running without retrieving its pending operation. This is a static residual, not an observed failure.
