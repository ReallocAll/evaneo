## Engineering finding {#engineering-finding}

Synchronous serve_forever starts a daemon handler thread for each accepted connection. The asyncio variant retains handler tasks until their done callbacks discard them. Both suppress ConnectionClosed and close the connection in finally; tests check echo and automatic closure when a handler returns. Async serving does not cancel or await the active task set when serving itself ends, and synchronous handler threads are not joined. Server shutdown ownership therefore remains a separate concern.
