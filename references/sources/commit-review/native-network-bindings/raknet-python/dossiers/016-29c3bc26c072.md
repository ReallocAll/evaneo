## Engineering finding {#engineering-finding}

Makes _abandon_connect report whether it removed a pending attempt. When a synchronous timeout loses the race to the pump, it waits for the pump event and closes any newly established connection before raising TimeoutError. Async cancellation closes only when pending.connection is already populated; it does not wait for the pump event in the corresponding gap. No regression test is added. Preserve the fixed sync ownership path and the static async residual separately.
