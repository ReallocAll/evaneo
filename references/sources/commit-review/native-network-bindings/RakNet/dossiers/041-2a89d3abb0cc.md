## Engineering finding {#engineering-finding}

EightPeerTest connects eight peers, waits up to20 seconds for a full mesh, broadcasts100 ordered packets from each, and checks per-sender sequence and exact100 receipts for each of the56 directed pairs. It drains while sending to avoid buffer buildup. MaximumConnectTest separates the getter assertion and an eight-peer oversubscription test that allows ten seconds to settle and checks each connection count <=4. The latter does not require any successful connection or count explicit refusals, so its contract is the cap alone. Alongside the tests, PostgreSQLInterface switches from POSTGRESQL_FOUND/include/library variables to the Conan-style imported target libpq::libpq; this meaningful build change is absent from the commit message. No configure, link or platform execution was attempted.
