## Engineering finding {#engineering-finding}

Adds gtest/1.14.0 through Conan, enable_testing(), one explicit tests executable, and gtest_discover_tests(). The root test option returns from OFF to ON. Initial migration includes CrossConnection, MessageSize and OfflineMessages; other legacy programs temporarily stop participating in the build. Fixtures use ephemeral ports and DestroyInstance cleanup. CrossConnection permits both simultaneous attempts to be accepted, requiring two total accepted/incoming notifications and one connection at each endpoint. MessageSize now inspects received p->data rather than comparing the original send buffer to itself; seven representative strides replace the exhaustive 1..1999 sweep. OfflineMessages checks advertise/pong bytes and lengths. These are inspectable test contracts, not an observed passing run. Fixed 100ms setup waits and ignored Send return values remain in MessageSize.
