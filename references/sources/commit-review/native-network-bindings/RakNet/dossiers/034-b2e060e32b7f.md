## Engineering finding {#engineering-finding}

ThreadTest replaces shared unsynchronized stop state and RakThread calls with std::atomic, std::thread and explicit joins before peer destruction. Ten producers and ten consumers share two peers; the assertion requires at least one packet received, not exact delivery, absence of races or a throughput level. The message explicitly cuts execution from 60 seconds to 3 seconds. StatisticsHistory replaces an infinite ASCII graph with five focused tests for retrieval, long-term bounds/sum agreement, merge, resample size tolerance and unknown-key errors. This is a maintenance and feedback-cost tradeoff; it does not imply the removed interactive run was a necessary release gate.
