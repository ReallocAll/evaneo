## Engineering finding {#engineering-finding}

FlowControl builds an explicit sender-relay-receiver topology, checks delivery counts at128ms pacing, and samples64/256/1024/4096-byte sizes at64ms pacing. The primary loop checks received lengths but the final drain only increments count, so it is not an all-packet content oracle. LoopbackPerformance sends approximately500 packets/second of400 bytes for3 seconds with a3-second drain, requiring all delivery for RELIABLE and RELIABLE_ORDERED and more than half for UNRELIABLE. It records sent/received counts, not elapsed throughput or speedup; the commit's measurement wording should not be promoted into a benchmark result. Removes TestDLL and RankingServerDBTest with explicit reasons: redundant no-assertion DLL check and PostgreSQL dependency unsuited to CI. The retired DLL program did exercise allocation/export boundaries, but no evidence establishes that restoring it is required; preserve that scope distinction.
