## Engineering finding {#engineering-finding}

The 168 changed files comprise 66 MDX pages (65 manual-oriented pages plus a substantially rewritten landing page), 71 copied images, one generated lockfile, and 30 navigation/scaffold/configuration files. The tutorial combines three previously separate code samples. The initial manuals retain almost all of their substantive upstream exposition; migration does not make their networking algorithms, anecdotes, benchmarks or recommendations new 2026 authorship. Information architecture replaces the old HTML presentation with ordered section metadata, frontmatter, MDX code fences, internal route links, images under public/images, tables and a root catch-all page. Root and per-section metadata were read. Seven root separator labels are subsequently removed in015 because the folders already supply section structure. The documentation route looks up page data, returns notFound for unknown slugs, renders title/description/table of contents/body, and derives static parameters and metadata from the same content source. Relative links pass through createRelativeLink. The source loader uses baseUrl=/, lucide icons, and processed Markdown. OG image routes use a 1200x630 WebP generator. The root uses the Inter font and Fumadocs provider. LLM-oriented routes expose an index of page titles/URLs/descriptions, an all-pages processed text representation, and a per-page text/markdown route. Page actions copy fetched Markdown with a loading state and cache; a menu opens the repository, raw MDX and several external assistant/editor links. This is evidence of making docs consumable by tools and readers, not proof those generated links resolve. No assistant service was contacted by this review. The scaffold uses Fumadocs core/UI 16.6.5, MDX 14.2.8, Next 16.1.6, React 19.2.4, Tailwind 4 and TypeScript 5.9.3. Its manifest includes dev/build/start, lint, type-check and postinstall generation scripts. The lockfile has 691 package entries and its root dependency sets match the manifest; dependency implementations and install scripts were not executed or audited. New landing-page prose presents a modern feature summary, seven-section navigation and local Doxygen instructions. It contains a SLNet security-layer claim, while the inherited secure-connections page documents LIBCAT/cat APIs. The earlier fork README already contains a SLNet encryption claim; this wording is not unique to the new landing page and is not evidence of new encryption integration. The platform summary is shorter than legacy lists and is not a new platform-validation result. Meaningful manual residuals include marking the old MasterServer2 hosted endpoint defunct, correcting three to four packet priorities and the destruction API name in detailed implementation, and repairing a replica return typo. C++ generic syntax in HTML had sometimes been parsed as tags; restoring it to fenced code can look like added text in an HTML-to-text diff and is not automatically a new API. Tutorial samples1–3 retain the old code/content token sequence after deleting introductory exercise descriptions; the deleted sample2 introduction had explicitly warned to drain Receive rather than call it once and to deallocate packets. Headers, manual footers and presentation details are removed/rearranged, and the SWIG toggle-script presentation becomes a comment before later cleanup. Original old APIs, old compiler paths, insecure/unbounded tutorial input and obsolete services remain in inherited examples. They are source content to audit, not recommendations adopted by the commit author. Four new Quick Start cards use /docs/getting-started/... although the content source is mounted at /. The section table uses the root form. The final static inventory still finds these four mismatches; this is a source-level route inconsistency, not a browser-tested404. Page actions request `${page.url}.mdx`, whereas the actual handler is /llms.mdx/[[...slug]]. The initial rewrite only matches /docs/:path*.mdx and injects docs into the destination; it does not obviously match the stated root route model. The later static-export commit removes the rewrite without changing the page actions. The initial GitHub source config names vince-carpino/RakNet/master. The generated source URL also lacks the repository docs/ prefix before content/docs. Commit 030 changes the owner to facebookarchive but keeps the same path construction. No external URL reachability was tested. The scaffold README lists app/(home) and app/docs routes that do not match this actual route tree.
