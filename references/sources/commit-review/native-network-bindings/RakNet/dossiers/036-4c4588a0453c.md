## Engineering finding {#engineering-finding}

Adds a ten-peer five-second mixed-operation crash smoke test and a nine-client fifteen-second disconnect/reconnect test. The latter uses two-second server timeouts, checks at most one connection per client, compares server connection count with client-side counts after timeout windows and guards reconnects against pending/connected states. The comprehensive workload inherits a broad random-operation shape from upstream but drops historical unused RPC branches and primarily asserts valid connection initiation plus survival. It does not measure leaks despite a later comment using that word. OfflineMessages gains GetOfflinePingResponse readback and nonempty/distinct GUID assertions. The message claims legacy ConvertTest behavior is fully covered; the diff shows representative migration, shorter runs and changed random scheduling, so that equivalence is author-reported rather than proven.
