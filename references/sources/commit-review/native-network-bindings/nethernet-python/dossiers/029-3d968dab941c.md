## Engineering finding {#engineering-finding}

wait_for now directly owns/cancels readiness Future rather than shield+consume callback, uses not-done guard to avoid orphan exception after timeout. Endpoint no longer redundantly marks every connection closed before transport close callbacks. Adds explicit timeout regression. Later HTTP code still needs marking exceptions retrieved when close occurs outside waiting; cancellation policy is resource-specific, not never-shield.
