## Engineering finding {#engineering-finding}

HTTP200 application/sdp can contain decimal session error, including36/37; previous response passed verbatim into aiortc causing misleading media-section ValueError. _parse_answer accepts v= SDP, known numeric errors -> ConnectionFailed, unknown numeric -> signaling unknown, nonnumeric junk -> parsing failure. Tests fake host returning37/36/9999/junk. This preserves meaningful error class but deliberately loses unknown numeric code.

> fix(http): raise the host's session error from a numeric answer body
