## Engineering finding {#engineering-finding}

Structs <HHQ8x, <I and <QI encode 20/24/32-byte headers without native alignment. Send truncates response/message payloads at1148/1140. Tests assert offsets, truncation, unknown types and short payload. Parser reads _packet_length but does not validate it against buffer length; validates individual payload extent, not all advertised invariants. Silent message truncation later causes SDP corruption.
