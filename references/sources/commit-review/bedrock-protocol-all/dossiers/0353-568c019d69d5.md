## Engineering reading {#engineering-reading}

Packaging moves public generated headers from package paths to bedrock/protocol module basenames, runtime helpers under the same include root, and exports static library bedrock::protocol. Generation can be skipped when the pregenerated umbrella exists, allowing a consumer install without Python; tests and fetched dependencies are conditional. CMake config/version uses SameMinorVersion and CI builds ABI-specific archives then a consumer with uv/uvx hidden. Eight moved runtime headers retain algorithms after include normalization; all meaningful CMake, packaging, compiler and residual changes were read. Flat module basenames impose a collision constraint on outside schemas. Public WIN32 compatibility flag from119 disappears; BuildPlatform gets macro-safe declaration handling rather than global platform undefinition. Author CI/package success is not reproduced; selected file-equivalence checks do not prove distributable correctness.
