## Engineering reading {#engineering-reading}

Handles nested/per-snapshot structs; excludes builtin types and Literal wire-only fields. Empty primaries permit generic probing. A missing name itself returns npos rather than a guaranteed diagnostic until used by an accessor. No dedicated tests added in this change;412 later documents the API.
