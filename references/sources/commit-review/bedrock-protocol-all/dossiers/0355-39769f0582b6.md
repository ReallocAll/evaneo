## Engineering reading {#engineering-reading}

Introduces recursive DynamicValue as handwritten builtin because DSL cannot spell self-recursion; no compiler extension needed since builtin module header convention already imports implementation. Seven fixed little-endian uint32 tags map null,bool,int64,double,string,array,object. Object deliberately std::map instead of BDS unordered_map for reproducible golden bytes across standard libraries, preserving order-insensitive wire semantics. Deserializer propagates errors/invalid tag, loops recursively without depth/count resource limits, duplicate object keys emplace keeps first. Tests cover all arms via nested golden and invalid tag; truncation/depth/duplicate behavior not tested in this diff. Later362/388 exposes integer constructor portability.
