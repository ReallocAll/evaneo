# Proposed retrieval cases {#proposed-retrieval-cases}

These are integration prompts and expected evidence boundaries, not a completed retrieval evaluation. Each points to full local dossiers.

## wire_shape_axis {#wireshapeaxis}
The same C++ type is written differently by two packets at the same protocol. Should I add an old-version alias?

Separate writer flavor from protocol; preserve the unmotivated revert and the later below844 GameRule correction.

## discriminating_fixture {#discriminatingfixture}
