## Current-head source-derived qualifications {#current-head-source-derived-qualifications}

These are static observations or risk hypotheses, not reproduced failures or a complete security audit. They apply to latest target2a8588900df533464d276b174a9e8a348e34df4f; the following bot0.3.3 stamp changes version/changelog only.

1. The failed-read replay guard is path-specific. Capture::fields refuses absent kDecoded at lines210–219, but export.cpp lines288–291 calls decode_body without that condition when details are requested, fields are null, body exists and the packet is lazy. View::draw lines64–66 advances the export on the draw path. The title of100 is broader than the implementation. See context-114-src-spyglass-overlay-capture.cpp-L180.txt, context-114-src-spyglass-overlay-export.cpp-L200.txt and context-114-src-spyglass-overlay-view.cpp-L1.txt.
2. Store lifetime is not joined. Store::~Store sets running false, notifies, detaches, then closes streams and removes files at lines187–205. The worker captures this and may still own a batch. Whether shutdown circumstances hide the risk was not tested.
3. Restart locks queues/index/readers but Store::run writes an already-swapped local batch outside those locks. No generation token guards old-batch writes or publication into a reset session. See store lines230–315 and337–393.
4. Failed writes still publish metadata/counters after reporting failure: store lines363–392. A healthy count is not proof the body reached disk.
5. Paging an old block assigns it then calls evict, which removes low-index blocks first; resident can return a null pointer for the very block it just loaded. See store lines397–442. The configured resident budget bounds resident blocks, not all block-pointer slots, rates or field-offset metadata.
6. Windows verify_client checks channel and patch-line lower bound, ignoring preview build and any upper bound; Android's function is empty. See signature.cpp lines96–114. Overlay installation precedes this network check, so README “installs nothing” is too strong.
7. General reflection recursion lost its depth guard in078, although NBT and error recursion remain bounded. A seen set for schema classification does not bound the value-rendering recursion. This review did not execute hostile or cyclic values.
8. Typed JSON is not a universal losslessness proof: enums remain strings; binary is an atob marker; text validation does not enforce every Unicode scalar restriction; replacement policies and report depth limits can affect output. Int and byte arrays can allocate outside the NBT node-count accounting.
9. Virtual-slot discovery stops below512 IDs. A unique factory signature and local Packet size assertion do not validate every external virtual layout, initialization state or memory permission. Linux slot restoration assumes read-only protection rather than recording previous flags.
10. Version/build source checks are not measured client outcomes. The descriptor slots for1.26.50/.60 were initially inferred from Linux protocol-dumper observations, and several safety assertions were removed. The author later reports focused NBT and virtual-table checks, with Android explicitly CI-only for099.
