# RakNetty: scope, provenance and causal history {#raknetty-scope-provenance-and-causal-history}

## Result {#result}

This is a bounded static review of all 57 target-attributed commits in the independent 2021–2022 NukkitR/RakNetty port. The strongest reusable evidence is the sequence of repairs to progress, retransmission identity, buffer cursors, event-loop dispatch and shutdown. It is not evidence of current personal preferences, full RakNet parity, a validated secure Bedrock stack, or measured performance.

The original selection and assignment audit is not bundled. This account and the [per-commit dossiers](../commits/001-790bb9721f5b.md) retain the reviewed scope and links to public history. The 2015–2017 Nukkit cohort and its dependent interpretations were not reopened. A contemporary `nukkit-api`, `nukkit-core`, parent-POM or BOM edge is recorded only as an edge in this repository. The destination implementation and transitive dependencies were not followed into excluded history.

## Attribution and evidence grades {#attribution-and-evidence-grades}

GitHub links every selected author to wu-vincent (user 8433134); Git author labels are MagicDroidX and Vincent Wu. All 57 reachable commit objects in this mirror are selected; there are no unselected collaborator commits in this DAG. This says who committed the changes, not who invented every algorithm. The initial transport comments name RakNet `ReliabilityLayer.cpp`, `CCRakNetSlidingWindow.cpp` and related APIs. The README explicitly identifies an Oculus/Facebook RakNet port built upon Netty. The copied 1,048-line `WrappedByteBuf` in [C39](../commits/039-ce529bc7d4f8.md) retains the Netty project's 2013 copyright and Apache-2.0 header. Its forwarding methods were inspected, but an exact upstream release/version match was not established. Do not credit wrapper boilerplate or RakNet algorithms as new inventions by the target.

Commit messages and inline reasons are explicit author evidence. Control flow and schema changes are observed implementation evidence. Benefits, failure scenarios and future test plans in these dossiers are reviewer inferences unless called reported. There are no reviews or objections in the commit records themselves; absence of review discussion is not agreement. The separately reviewed [Issue #1 dossier](../../../thread-review/threads/dossiers/NukkitR__RakNetty-1.md) contains BroPro40's question and Vincent's claim of broad implementation, with no feature matrix or validation. It remains project-intent evidence only.

- [C01](../commits/001-790bb9721f5b.md)–[C08](../commits/008-f3aa1a48e07f.md) bootstrap an incomplete Java/Netty port, then implement serialization/fragmentation and repair several first-pass defects. - [C10](../commits/010-362e683cd026.md)–[C21](../commits/021-dbc4e1a5da71.md) repair IPv4 framing, ACK flushing, handshake state, client promises, retransmission and active/inactive events. - [C22](../commits/022-a0ae0658193d.md)–[C31](../commits/031-334efa71fd4d.md) stage pipeline isolation, change the public payload API twice, add a forwarder, fix the receive-hole infinite loop and nonblocking shutdown, and defend retransmission slots.

## Efficient review without inflated credit {#efficient-review-without-inflated-credit}

Every message and meaningful changed source was read, including actual parent comparisons. DAG audit proves both merges equal the other branch's delta from the common ancestor, with no additional resolution delta. [C16](../commits/016-73cb20de3982.md) incorporates [C14](../commits/014-e82c81634792.md)/[C15](../commits/015-2d9f2c0acca9.md); [C56](../commits/056-07a79ae4009c.md) incorporates [C53](../commits/053-4d45b4572389.md)+[C54](../commits/054-344932b55073.md) and [C55](../commits/055-4e43ce6a6067.md) from common base [C52](../commits/052-50b33ad4f2ee.md). These are integrations, not additional independent lessons.

[C07](../commits/007-66ae15a457fa.md)'s large split includes 605 equal added and 605 equal removed lines verified by exact block identity; revised wiring and the residual were read. This is textual movement evidence, not automatic semantic equivalence. [C43](../commits/043-24a3e0a1e1fe.md)'s raw 13,340-line delta becomes 1,581 lines with rename detection: 51 exact-blob renames, 11 modified renames whose hunks were read, plus new/deleted files. [C40](../commits/040-b1629bfe80ba.md) deletes 55 files / 5,265 lines; deletion audit maps each old blob to the already read [C33](../commits/033-7d52b850ceb9.md)/[C35](../commits/035-398af46ee855.md)/[C39](../commits/039-ce529bc7d4f8.md) version. The nondeletion residual was fully read; the move to another repository is not verified here.

[C01](../commits/001-790bb9721f5b.md)'s standard GPLv3 license receives identity/structural disposition, not a fresh line-by-line legal interpretation. [C53](../commits/053-4d45b4572389.md)/[C54](../commits/054-344932b55073.md) are verified POM-only release-plugin changes. Repeated titles [C44](../commits/044-35795928db7f.md)/[C45](../commits/045-8b850e0cb248.md) are not duplicates: [C45](../commits/045-8b850e0cb248.md) corrects [C44](../commits/044-35795928db7f.md)'s wrong example exclusion path. These concise dispositions preserve each SHA without manufacturing preferences.

## Review limits {#review-limits}

Three credential-guard opaque lines in [C35](../commits/035-398af46ee855.md) recur in [C40](../commits/040-b1629bfe80ba.md)'s deletion. They were not bypassed or reconstructed. All supplied nonopaque meaningful changes were reviewed; this is not a claim to have read hidden contents. No source, build, dependency installation, test, example, packet capture or benchmark was executed. Extraction, blob/patch comparisons and local document validation are research utilities only. The source snapshots are several years old. Use the lessons as conditional design questions, with contemporary requirements and tests determining the answer.
