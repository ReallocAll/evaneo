# Keep compatibility proportional to real commitments {#overview}

## Rationale {#rationale}
Unpublished private formats may be replaced when authorized, whereas public interfaces, ownership, security and data integrity require more care. Make boundaries and mitigation tradeoffs explicit; do not add generalized guards unless they protect a real commitment.

## Case and counterexample {#example}
A redundant private configuration reader can be removed, but a public configuration override must not be deleted merely because its implementation is inconvenient.

## Applicability {#applicability}
Use for migrations, public interfaces, security measures and native boundaries.

## Evidence boundaries {#limits}
This account summarizes historical decisions and their limits. It is not an authorization to perform new work and does not override a current repository contract.
